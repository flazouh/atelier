## What is new in 0.1.6
Released: 2026-10-09
### New
- **The usage dashboard:** press the usage chips at the bottom of the window to see what Claude Code and Codex spent on this computer. It shows tokens per day, the models and the sessions, with a chart for each session. Press an account to see only that account.
- **Several accounts:** each Claude Code account gets its own tile and its own shade, grouped under one caption.
### Improved
- **The version in the status bar:** it stands at the bottom left, left of the CPU. CPU and RAM moved to the right. Press the version to read the changelog.
- **The release notes:** six kinds of note, each with its own icon and colour.
