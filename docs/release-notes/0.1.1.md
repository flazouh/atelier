## What is new in 0.1.1

- **Files tree:** a menu on each row (the ⋯ button or a right press): new file, new folder, rename, duplicate, delete, copy path, show in the file manager and mention in a session. Names are typed in the tree.
- **Tabs in the title bar:** the single view's session tabs and the Files view's file tabs sit in the title bar.
- **Edits beyond the project:** a file an agent writes or edits outside the project folder now shows in the changed files, with its full path, and you can review, accept or reject it. This also works over SSH.
- **Marks in the Files tree:** a dot shows on a file, or a folder, that a session changed. A press opens that session's review.
- **Fixes:** a tree row fills the tree's width, and Escape or a click elsewhere ends a name you were typing.

The remote helper changes (protocol 8). Atelier updates the helper on a remote host the next time you open it.
