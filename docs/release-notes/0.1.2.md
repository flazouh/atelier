## What is new in 0.1.2

- **Updates in our own window:** Atelier looks for an update by itself, downloads it in the background and shows a small "Update ready" button in the title bar. The button opens the changelog. Press "Restart and update" to install, or "Later" to install when you quit.
- **No more system windows:** the update dialogs from the system updater are gone. Progress, the changelog and the choice all show in Atelier.
- **Notes inside the feed:** the changelog now travels with the update, so it always shows.
